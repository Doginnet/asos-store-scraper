# Target: ASOS (asos.com)

- **Domain Category:** E-commerce / Fashion Retail
- **Base URL:** https://www.asos.com
- **Anti-Bot Level:** Akamai Bot Manager (API endpoint accessible with browser TLS & signature headers)
- **Selected Extraction Strategy:**
  - **Primary:** Intercepted REST API (`GET https://www.asos.com/api/product/search/v2/categories/{category_id}`)
  - **Fallback:** Camoufox (Virtual / Native Headless)
- **Signature Headers & Parameters:**
  - `asos-c-plat`: `Web`
  - `asos-c-ver`: `5.0.0`
  - `asos-c-name`: `asos-web-ui-library`
  - `asos-cid`: Dynamic UUID4
  - `keyStoreDataversion`: `7qyyrb1-46`
  - `channel`: `desktop-web`
  - `country`: `BG` (or configurable)
  - `currency`: `EUR`
  - `store`: `ROE`
- **Pagination Mechanism:**
  - Query parameters: `limit` (default: 72, test: 16), `offset` (0, 72, 144, ...)
  - Total items indicator: `itemCount` in response root
- **Concurrency & Rate Limits:**
  - Max 2 RPS, randomized jitter 0.5s - 1.5s, exponential backoff on 429/403
- **Target Data Schema:**
  - `src/models/product.py -> AsosSearchResponse, AsosProduct, AsosPrice`
- **Single Smoke Test URL:**
  - `https://www.asos.com/api/product/search/v2/categories/5775?channel=desktop-web&country=BG&currency=EUR&keyStoreDataversion=7qyyrb1-46&lang=en-GB&limit=16&offset=0&rowlength=4&store=ROE`
