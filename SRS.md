## 1. Концепция и Назначение (Vision & Scope)

- **Суть приложения:** Высокопроизводительный, отказоустойчивый скрейпер каталога и монитор ценовой динамики для маркетплейса **ASOS**. Проект взаимодействует с закрытым внутренним REST API витрины, обходит защиту Akamai Bot Manager через аппаратную TLS/JA3 имперсонацию браузера Google Chrome, валидирует схемы данных контрактами Pydantic v2, ведет версионирование цен в реляционной БД SQLite и предоставляет аналитический веб-интерфейс на Streamlit вместе с модулем Telegram-алертинга.
- **Целевая аудитория и юзкейсы:**
  - *E-commerce аналитики & Байеры:* Мониторинг скидочных кампаний брендов (Nike, adidas, New Balance), глубины уценки и динамики снятия товаров с продажи.
  - *Арбитраж и ритейл-хантинг:* Мгновенный перехват clearance-позиций со скидками до -80% и выше.
  - *Data Engineering портфолио:* Демонстрация продакшен-архитектуры парсинга без тяжелых браузерных движков (Playwright/Puppeteer).
- **Ключевая ценность:** Скорость извлечения до 50x выше по сравнению с браузерной автоматизацией, минимальное потребление RAM/CPU, 100% точность каталожного учета и автоматический учет выбывших позиций.

## 2. Дизайн и Эстетика (UI/UX & Aesthetics)

- **Интерактивный Dashboard (Streamlit):**
  - **Цветовая палитра:** Тёмная аналитическая тема (`#1E232F` карточки, `#0E1117` фон, акцентные красные бейджи скидок `#E53E3E`, зеленые цены `#48BB78`).
  - **Компоненты интерфейса:**
    - Боковая панель: выбор категории с отображением активных/исторических товаров, слайдер скидки (0–90%), лимит цены, фильтр по брендам и поиск по ключевым словам.
    - Верхний блок ключевых метрик: объем каталога в фокусе, число найденных скидок, максимальная скидка в выборке, средняя цена.
    - Вкладка «Deal Cards Showcase»: адаптивная сетка карточек с фото, текущей и старой ценой, процентом скидки и прямой ссылкой на страницу ASOS.
    - Вкладка «Market Analytics»: рейтинг брендов по скидкам, распределение глубины уценки (1-20%, 21-40%, 41-60%, 61-80%, 81-100%), объемы категорий.
    - Вкладка «Data Explorer»: таблица с поддержкой сортировки, метаданными жизненного цикла (`is_active`, `last_seen_at`) и кнопками моментального скачивания в CSV/JSON.
    - Вкладка «Telegram Alerting Simulation»: статус интеграции, настройка порога срабатывания и интерактивный предпросмотр HTML-шаблона сообщения.
- **Консольный CLI (Rich):**
  - Цветные таблицы топ-скидок с процентными скидками, статусами пагинации и жизненного цикла.

## 3. Функциональные требования (Functional Requirements)

### FR-1: Обход Akamai Edge CDN & Контекстная маршрутизация
- Использование библиотеки `curl_cffi` с точной имитацией TLS/JA3 фингерпринта Chrome 124 и протокола HTTP/2.
- Корректная сессионная маршрутизация Edge CDN: передача необходимых cookies (`currency: 19`, `storeCode: ROE`, `browseCountry: BG`, `siteChromeVersion`), полностью предотвращающая ошибку HTTP 400 `No valid store was found`.
- Санитизация локали: принудительная конвертация системных POSIX-локалей (например, `en_US.UTF-8`) в IETF-код `en-GB`.

### FR-2: Автоматическая пагинация каталога
- Поддержка извлечения до 72 товаров за один сетевой запрос (максимальный размер страницы ASOS API).
- Динамическое вычисление общего числа товаров из поля `itemCount` ответа API.
- Режимы работы: пошаговый (`--max-items N`) и полный обход всей категории (`--all`).

### FR-3: Строгая Pydantic v2 валидация данных
- `AsosPrice`: извлечение `current`, `previous`, `rrp`, расчет скидки `@property discount_percent`.
- `AsosProduct`: нормализация неполных URL картинок и ссылок на товар (добавление `https://www.asos.com/`), обработка отсутствующих изображений.
- `AsosSearchResponse`: целостная валидация постраничного ответа API.

### FR-4: Реляционное хранилище SQLite
- Таблица `products`: уникальные карточки товаров (`ON CONFLICT(id) DO UPDATE`).
- Таблица `price_history`: история срезов цен для отслеживания динамики скидок во времени.
- Таблица `categories` & `product_categories`: Many-to-Many связка для точной каталогизации товаров.
- SQL Window функции (`ROW_NUMBER()` CTE) для исключения дубликатов в счетах топ-скидок.

### FR-5: Отслеживание жизненного цикла (Lifecycle Management)
- Фиксация времени последнего обнаружения товара `last_seen_at` и флага активности `is_active`.
- При полном сборе (`--all`) все товары категории, не вернувшиеся в текущем проходе витрины, переводятся в статус `is_active = 0`.
- Фильтрация запросов топ-скидок и каталога по умолчанию по `is_active = 1`.

### FR-6: Мультиформатный экспорт данных
- Экспорт выборок по категориям в `data/samples/<category>/` (`deals.csv`, `deals.json`, `products.csv`, `products.json`).
- Экспорт сводных глобальных каталогов в `data/samples/summary/` и корне `data/samples/`.

### FR-7: Telegram-алертинг
- Модуль `TelegramAlerter` с HTML-разметкой карточки скидки.
- Безопасный **Mock / Simulation Mode** при отсутствии токенов в конфигурации.

## 4. Нефункциональные требования (Non-Functional Requirements)

- **Производительность:** Время парсинга 1 страницы (72 товара) — менее 0.7 сек. Сбор 2 300+ позиций занимает ~20-30 секунд.
- **Изоляция:** Строгая работа внутри виртуального окружения `.venv`, управление через менеджер `uv`.
- **Надежность:** Экспоненциальный откат (retry backoff) при сетевых задержках (3 попытки, backoff factor 1.5).
- **Тестовое покрытие:** Наличие юнит-тестов offline-валидации и live-тестов реального API (100% PASS).
