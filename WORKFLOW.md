# 🔄 Алгоритм работы (Workflow Pipeline)

> **Проект:** ASOS E-commerce Catalog & Price Monitor  
> **Формат:** Пошаговая последовательность действий пайплайна

---

### 1. Инициализация и подготовка сессии
1. **Загрузка конфигурации:** Чтение параметров из `.env` и `settings.py`.
2. **Разрешение региона:** Автоматическое сопоставление `country -> store -> currency` (например, `BG -> ROE -> EUR`), исключающее сбои роутинга.
3. **Инициализация HTTP-клиента (`curl_cffi`):**
   - Установка TLS/JA3-фингерпринта Chrome 124 и HTTP/2.
   - Подключение валидного набора сессионных Edge-кук Akamai (`currency: 19`, `storeCode: ROE`, `siteChromeVersion` и др.).
   - Принудительная санитизация локали на `en-GB`.

---

### 2. Подготовка хранилища (Database Setup)
1. **Инициализация SQLite:** Подключение к `data/asos.db` (режим WAL).
2. **Проверка схемы и автомиграция:** Проверка таблиц `products`, `price_history`, `categories`, `product_categories` и колонок жизненного цикла (`last_seen_at`, `is_active`).
3. **Фиксация времени старта:** Сохранение `scrape_start_time` (UTC таймштамп) для последующего контроля выбывших товаров.

---

### 3. Постраничный сбор данных (Pagination Loop)
1. **Запрос к REST API:** `GET /api/product/search/v2/categories/{id}` с размером страницы `limit=72` и текущим `offset`.
2. **Определение объема каталога:** На первой странице считывается `itemCount` (общее число позиций на витрине ASOS).
3. **Pydantic-валидация:**
   - Преобразование JSON-ответа в модель `AsosSearchResponse`.
   - Валидация карточек через `AsosProduct` и цен через `AsosPrice`.
   - Автоматическая нормализация ссылок (приведение к `https://www.asos.com/` и `https://images...`).
4. **Контроль темпа:** Вежливая пауза (`0.5 – 1.2 сек`) между запросами страниц.
5. **Условие завершения:** Достижение `itemCount`, достижение лимита `--max-items` или пустой список товаров в ответе.

---

### 4. Сохранение данных и дедупликация (Persistence)
1. **Upsert товаров (`products`):**
   - Добавление новых карточек или обновление существующих (`ON CONFLICT(id) DO UPDATE`).
   - Установка флага `is_active = 1` и обновление времени `last_seen_at = now`.
2. **Запись истории цен (`price_history`):**
   - Добавление среза цен (текущая цена, старая цена, процент скидки, валюта).
3. **Привязка категорий (`product_categories`):**
   - Связывание товара с категорией (Many-to-Many связка).

---

### 5. Актуализация жизненного цикла (Lifecycle Sync)
*Выполняется при запуске полного сбора категории (`--all`):*
1. **Поиск выбывших товаров:** Сравнение товаров категории с временем `scrape_start_time`.
2. **Деактивация:** Товары, не встреченные в текущем цикле витрины, переводятся в статус `is_active = 0`.
3. **Фиксация:** Логирование количества деактивированных позиций.

---

### 6. Выгрузка и формирование отчетов (Export Pipeline)
1. **Дедупликация скидок через SQL Window CTE:**
   - Выборка топ-скидок с фильтром `is_active = 1` через `ROW_NUMBER() OVER (PARTITION BY product_id ORDER BY id DESC)`.
2. **Экспорт по категориям:**
   - Запись в `data/samples/<category>/` файлов `deals.csv`, `deals.json`, `products.csv`, `products.json`.
3. **Глобальный экспорт:**
   - Обновление сводных файлов всего каталога в `data/samples/summary/` и корне `data/samples/`.

---

### 7. Доставка и визуализация (Delivery & UI)
1. **Rich CLI:** Вывод форматированной таблицы топ-скидок в терминал.
2. **Telegram-алертинг:** При наличии флага `--notify` проверка порога скидки (>= 60%) и отправка карточек (в боевом или Mock-режиме).
3. **Streamlit Dashboard:** Загрузка актуального среза из SQLite в веб-интерфейс (`uv run streamlit run src/dashboard/app.py`).

---

### 8. Периодическая автоматизация (GitHub Actions CI/CD)
1. **Триггеры:** Запуск по расписанию (`cron: '0 6 * * *'`) или вручную через `workflow_dispatch`.
2. **Окружение и тесты:** Установка Python 3.12 через `astral-sh/setup-uv`, запуск юнит-тестов (`pytest`).
3. **Сбор данных:** Автономный полный сбор всех категорий каталога (`--all-categories --all`) с флагом `--notify`.
4. **Автокоммит (Flat Data):** Коммит обновленной базы `data/asos.db` и выборок `data/samples/**` от имени `github-actions[bot]`.
5. **Резервная копия:** Загрузка `data/asos.db` в GitHub Actions Artifacts (хранение 30 дней).
